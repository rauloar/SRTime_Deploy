# Refactor de robustez, seguridad y paridad — 2026-07-21

## Alcance

El proyecto local es la fuente de verdad. El remoto se utilizó una única vez como base del commit `67612e5`; no contenía una variante superior del refactor.

Arquitectura productiva resultante:

- PySide6/Windows y Web consumen la misma lógica en `attendance/services/`.
- Next.js genera un export estático (`web/out`).
- FastAPI sirve `/api/*` y el frontend estático. No existe servicio Node en producción.
- PostgreSQL es el motor productivo; SQLite conserva compatibilidad para desktop y tests.

## Cambios funcionales

- `MetricsCalculator`, justificaciones y reportes son contratos compartidos.
- PDF mensual Web/Windows usa `build_monthly_pdf`; se corrigió el contrato de campos.
- Una marcación única genera `INCOMPLETO` en vez de descartarse.
- Los OUT nocturnos del día siguiente se asignan a la jornada de inicio.
- Los dispositivos sin dirección confiable alternan marcaciones cronológicamente.
- Los logs inválidos quedan fuera del procesamiento y se informan como errores.
- El parser TM-MR001 por defecto es `SundialParser`; se eliminó el parser duplicado.
- La ruta elegida por Windows se guarda con `QSettings`, nunca dentro de raw logs.
- La importación ya no renombra, vacía ni reemplaza automáticamente el archivo fuente.

## Terminales y addons

- El registry cachea el descubrimiento y mantiene `driver_class`/`parser_class` separados.
- `DeviceTerminal.connection_params` permite campos definidos por cada manifest.
- `services.terminals` centraliza parámetros, test, sincronización y pull.
- Los secretos se excluyen de respuestas API y se cifran con Fernet antes de persistir.
- Registros legacy en `password` siguen siendo legibles; al editar se trasladan cifrados al JSON.
- Hikvision aplica timeout por request y permite configurar zona horaria/filtro minor.
- Hikvision interpreta minor `76` como OUT; ZKTeco normaliza estados desconocidos a IN.
- Un pull fallido propaga error y no actualiza `last_sync`.

## Seguridad

- Cookie JWT HttpOnly/SameSite para Web; Bearer continúa disponible para integraciones.
- JWT incluye `iat`, `jti`, issuer, audience y versión revocable.
- Cambiar contraseña incrementa `token_version` e invalida tokens anteriores.
- Expiración por defecto: 60 minutos, configurable.
- Contraseña mínima: 12 caracteres, configurable.
- RBAC: viewer lectura; supervisor/admin operaciones; root borrados, aprobaciones y reproceso total.
- Upload TXT por streaming, extensión validada y límite configurable de 10 MiB.
- Rate limits en login, importaciones y procesamiento.
- CORS sin IP LAN hardcodeada y cabeceras CSP, Referrer-Policy y Permissions-Policy.
- IPs, rutas, usuarios y contraseñas de terminal no tienen defaults productivos hardcodeados.
- `TM-MR001.txt` real se conserva local pero queda fuera del control de versiones; los tests usan mock.
- Dependencias auditadas: cero vulnerabilidades conocidas en requisitos Python y dependencias npm de producción al cierre de la sesión.

## Rendimiento y consumo

- Ingesta PostgreSQL por lotes con `ON CONFLICT DO NOTHING`.
- Mensajes de ingesta limitados a los últimos 200.
- Motor precarga empleados, turnos y procesados, evitando consultas por jornada.
- Agregaciones de reportes/resumen se realizan en SQL.
- Excel Web se genera en FastAPI; se retiró `xlsx` del navegador.
- Registry de addons cacheado.
- Advisory lock PostgreSQL impide reprocesos concurrentes. SQLite usa lock de proceso.
- Se eliminó el servicio Node/puerto 3000 del deploy.

## Rollback

El código puede revertirse por Git. Para esquema, `alembic downgrade b2e9d45f8c11` elimina las columnas nuevas, pero no restaura la fila dummy ni descifra/mueve valores de `connection_params` al campo legacy. Respaldar PostgreSQL antes de un rollback productivo.
